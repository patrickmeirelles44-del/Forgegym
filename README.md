# RepForge Gym
Aplicativo de academia gamificado — base inicial.

## Rodar localmente
```bash
npm install
npm run dev
```

## Escopo inicial
- Painel com XP e progresso
- Treinos predefinidos e exercícios editáveis
- Perfil com altura, peso e idade
- Teste de acesso à câmera (a análise de pose ainda não está implementada)
- Interface responsiva para celular e desktop

O progresso nesta primeira versão fica apenas na memória do navegador. Supabase será conectado depois de confirmar o projeto ativo correto. Nenhuma chave secreta deve ficar no frontend.
